Momentum is an iOS habit-tracking app built with SwiftUI. Users can pick the habits they'd like to build, check them off each day, and watch their streak and weekly progress grow.

**FEATURES**
• Home dashboard with a personalized greeting, current streak, and easy navigation to every screen
• Daily check-in that lists today's habits as a checklist and logs progress when you finish
• Streaks that grow by one day whenever at least one habit is completed
• Stats with a weekly bar chart that shows how many habits were completed each day
• Habit management for adding, deleting, and choosing the habits you want to show up on the check-in
• Settings for changing your display name, background color, and notifications
• Onboarding flow for first-time users

The color scheme was chosen with motivation psychology in mind, so the app feels encouraging without adding stress.

**TECH STACK**
• Swift and SwiftUI
• Supabase
• Xcode
• Figma and FigJam for mockups

**RUNNING THE APP**
1. Clone this repo or download it as a ZIP.
2. Open Momentum/Momentum.xcodeproj in Xcode.
3. Pick an iPhone simulator, or plug in your iPhone and select it as the run target.
4. Press Run.

A full walkthrough of every screen is in the User Guide
